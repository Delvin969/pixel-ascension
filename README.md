# Pixel Ascension

Struktur awal proyek game pixel-art berbasis HTML Canvas.

## Menjalankan
1. Ekstrak folder/ZIP.
2. Buka `client/index.html` di browser.
3. Gerakkan kotak karakter dengan tombol panah atau WASD.

## Struktur aset
- `client/assets/images/player` — karakter pemain
- `client/assets/images/weapons` — senjata
- `client/assets/images/monsters` — monster
- `client/assets/images/bosses` — boss dungeon
- `client/assets/images/chests` — peti harta
- `client/assets/images/ui` — ikon dan antarmuka
- `client/assets/audio/bgm` — musik latar
- `client/assets/audio/sfx` — efek suara
- `server` — tempat kode server multiplayer Node.js nantinya

Folder aset saat ini kosong dan siap diisi file gambar/audio.
